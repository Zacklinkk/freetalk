# 首次使用引导

首次启动自动显示引导，完成后记住状态。从菜单或本地模型页可以再次打开。没有完成时关闭窗口，下次启动仍会显示，避免静默停在不可用状态。

## 五个步骤

1. **认识 freetalk**：说明输入位置、离线处理和不自动发送，展示一个明确标注为「效果示例」的口述改口例子。
2. **准备本地模型**：显示两个模型、下载量、许可、文件状态和真实下载进度。支持单独下载、取消、重试和完整校验；模型实际加载好后才允许继续。
3. **连接你的输入框**：分别说明麦克风、跨应用输入、右 Option 的用途，显示实时授权状态，不用一个含糊的总授权按钮。只允许麦克风时也可以先试说。
4. **试说一句**：用真实麦克风和本机模型，显示音量、识别原稿、整理结果、停止到文字的耗时以及整理的实际状态。可重试或跳过。最近 10 次结果仅保留在进程内存中，可切换对照，退出应用即清除；此会话没有外部输入目标，也不写入普通历史。未解决的改口会提示检查原稿，不把模型已调用等同于整理成功。
5. **准备完成**：汇总实际状态，介绍词库、学习撤销和 500 条历史；不会把未授予的权限标记为可用。

视觉采用原生 AppKit 控件、薄荷色音量条和清晰的左右分区，与菜单栏与录音胶囊相呼应，支持明暗外观。

## 设计参考的边界

参考了 Typeless 的「先说明收益，再实际试说，随后理解整理效果」引导思路，以及其公开的 [快捷键与麦克风设置说明](https://www.typeless.com/help/quickstart/settings)。freetalk 使用自己编写的界面、文案、示例和提示词，不包含 Typeless 的代码、图形资产或私有服务提示词。公开参考并不能证明两者模型或服务端实现相同。

## 手工验收

- 空用户目录打开：应出现引导，没有模型时不能假装就绪；下载页不能读取其他用户的资源。
- 下载中取消并重试：进度可恢复，失败不改掉可用配置；校验旧模型不重复下载。
- 权限逐项允许或拒绝：状态正确更新，拒绝麦克风时不能开始试说。
- 试说提示句：实际读一遍，观察音量和原稿/结果；确认外部草稿与普通历史均未变化。
- 连续试说后切换「查看试说」：每次的原稿、结果和整理状态对应；第 11 次完成后淘汰最旧的试说，退出重启后列表清空。
- 试说中关闭窗口或按 Esc：停止录音，不留下输入；无声时显示明确提示。
- 完成后重启：不再自动显示引导；菜单可以再次打开。
- 正常跨应用输入：保留既有草稿；录音过程中切换输入框后，不应向新位置盲目粘贴。

物理麦克风、系统权限、焦点变化与无障碍兼容性必须在真实 macOS 上验证，自动测试不能替代这些验收。
