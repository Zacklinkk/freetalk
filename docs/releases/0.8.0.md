# freetalk 0.8.0

改字时删掉的口水词、调整的标点会学成整理习惯；每类应用可以选不同的语气。新增夜间整理（从口述高频词生成用户画像和转写热词）和线上会议的双轨录音；轻声说话的长口述不再被切碎。

- **整理习惯**：插入后删掉整理留下的口水词（句首的“就是”、开头的“然后”、“那个，”）、补回被删的语气词、去掉或补上句末句号、在“但是、所以”等连接词前加逗号、在中英文之间加或去空格，都会学成习惯。删除和改动类的习惯第二次出现才生效，补回的词立即保留；生效时显示 5 秒撤销提示。在「常用词与学习 → 管理已学会的词和习惯 → 整理习惯」查看和移除。
- **观察改字更久**：插入后至少观察 90 秒，每次改字后再等 30 秒，最长 10 分钟。改完马上发送消息，最后一次修改也会学到。
- **按应用调整语气**：「语音输入 → 专业配置 → 按应用调整语气」给聊天、工作沟通、邮件、文档、笔记、AI 助手等每类应用选自然（默认）、正式或口语。正式去掉句末的呀、啦、哈、呗并补上句号；口语保留语气词，一句话的消息不加句号。内置约 180 个常用应用和 90 多个网站的类别，浏览器按网页域名区分。AI 助手的输入框改为粘贴纯文本。
- **夜间整理**：「常用词与学习 → 夜间整理」打开后，每晚 00:30–06:00 电脑空闲时运行，两项可以分别开关。“画像与转写热词”从你的口述里反复出现的词推断常谈的领域，把领域里的专业词（例如 benchmark、LoRA）加入语音识别的热词，只发送词和次数，不发送句子；“整理规则优化”就是 0.7 的每晚自动优化，原来的设置自动沿用。点「立即运行」马上执行。需要「云端模型」里的强模型。
- **会议双轨录音**：会议「选项」勾选“同时录制电脑播放的声音”后，线上会议的远端声音另录一条音轨（需要“屏幕录制”权限，只录声音不录画面）。两条音轨分别转写，原稿标出本机和远端；没戴耳机时，麦克风录到的扬声器回声会去掉。
- **轻声说话**：停顿判断随说话音量调整，轻声或耳语的长口述不再每 8 秒从字中间切开。
- **修复**：在 1 倍分辨率的外接显示器上，“识别窗口里的文字”读不出字。
- **云端提示**：云端返回 HTTP 403 时，提示“云端拒绝了请求（密钥无效或额度已用完）”。

用了云端功能的话，更新后第一次读取密钥时钥匙串会再询问一次，请选择“始终允许”；夜间整理只在当天读到过密钥后运行，不会在夜里弹出询问。

286 项 Python 检查、17 组 Swift 检查、应用构建与签名结构校验，以及设置界面启动检查通过；在本机的真实应用里跑通了翻译快捷键、富文本粘贴、整理习惯、会议录音和夜间整理。双轨录音和窗口文字识别需要“屏幕录制”权限，用同一份代码在有权限的终端里验证。当前公开构建未做 Apple 公证。
