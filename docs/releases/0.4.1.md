# freetalk 0.4.1

- 新增「录音时长」设置：1 分钟、90 秒、3 分钟、5 分钟、10 分钟及 30–600 秒自定义。新用户默认 3 分钟；升级保留此前有效的 90 秒等设置。
- 到达上限前 10 秒，输入位置浮窗显示倒计时；音量阶梯轻旋一次，从薄荷绿平滑转为红色。支持 macOS「减少动态效果」，此时只变色、不旋转。
- 倒计时与自动停止共用单调计时，麦克风准备时间不占用录音额度；本次上限在开始时固定，停止或取消后自动复位。
- 语音输入设置页可滚动，较小窗口也能访问全部选项。会议录音仍使用独立的 8 小时上限。

本次不更换模型，也不增加权限。普通口述的时长限制属于应用设置；长篇讨论建议使用「会议资料」。
