# freetalk 0.4.0

- 新增可选「会议资料」：导入 WAV / M4A / MP3 / FLAC，或用当前麦克风录制长会议。默认关闭，启用后才处理会议；第一版不含电脑播放声音混录。
- 复用已有本地 ASR 和 4B 整理模型，生成带片段时间戳的原稿、分类纪要和可展开脑图。原稿先可用，纪要继续生成；中止或失败保留进度供重试。
- 按需下载约 107 MB 的 Nemotron-3 说话人模型，在本机区分最多 8 个匿名说话人。支持官方源、镜像、进度、续传和校验；不识别真实姓名。
- 可选择兼容 API 的云端纪要模型：显式配置后只发送转写文字，录音留在本机。密钥存入 macOS 钥匙串。
- 纪要包含原文引用、未指定的负责人/期限和待复核提示；脑图保留已提取事实的引用。可导出 Markdown、JSON、Mermaid 和离线 HTML。
- 安装包附带 CLI 和 freetalk-meetings skill，供 Claude Code、Codex 搜索、分页读取、核对出处和生成进一步内容；不启动网络服务。

会议功能仍为实验性：专业缩写、远场多人抢话和复杂跨段语义需复核；机器初稿不代表最终决议。会议资料单独保存，不套用普通口述的 500 条上限。默认成功后删除临时录音，可自行开启保留。

本次不增加系统权限。当前发布仍使用临时应用签名；若更新后原有权限未生效，请按权限引导重新关联当前安装的 freetalk。
