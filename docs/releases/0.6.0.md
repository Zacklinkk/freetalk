# freetalk 0.6.0

口述整理少改错，也会整理标点和断句；学习从记住词对改为总结你的修改习惯；可以选用更准的识别模型和云端整理模型。设置页分成常用设置和折叠的专业配置。

- **云端整理（可选）**：在「语音输入 → 专业配置」填写 OpenAI 或 Anthropic 兼容的服务。云端超时、拒绝或返回无法使用的结果时，本次自动改用本机模型，浮窗显示原因。云端结果和本机结果经过同样的安全校验；当前窗口的可见文字不发送到云端。
- **标点与断句**：整理模型可以合并被停顿切开的半句、给长句补逗号、把问句末尾的句号改成问号。引号、括号和代码里的标点、感叹号和真实的问句不会被改掉。分段处落单的语气词会归位（“效果会更好。的” 改为 “效果会更好的。”），删除口水词后不再留下多余的逗号。
- **口吃与叠字**：“我我”“登登录”这类口吃照常删除；“一下下周二”“马上上线”“这个功能能不能用”这类前后两个词相接的叠字不再被误删。
- **整理规则优化**：插入后你又改动的口述会记在本机。积累 3 条以上，可以在「学习」页请云端模型把它们总结成几条整理偏好。本机先用新旧规则重跑这些记录并给出对比，你确认后才生效，也可以随时恢复默认规则。
- **改字学习**：区分识别错误和整理错误，按出现次数和时间衰减。中文改字容忍一个字母的口音差异（如 z/zh、n/ng），不再要求正确词已经在词库里。学到的写法在语境无歧义时直接生效，热词按当前上下文排序。
- **识别模型可选**：「模型」页可以下载并切换 Qwen3-ASR-1.7B。标准普通话测试错字少约三成，会议录音错字率从 18.7% 降到 17.1%；代价是识别时间约为 0.6B 的 2.5 倍，和整理模型合计常驻约 5.1 GiB。日常口述仍推荐 0.6B。
- **自动输入**：输入框里光标以外的位置有变化（例如上方还在流式输出）时也能直接插入，只有光标附近被改动时才改为复制。网页编辑器的插入核验减少误判。快捷键失效的问题已修复，并可自定义快捷键。
- **钥匙串**：云端密钥在后台读取，每个版本最多询问一次，不会在开始录音时弹出。应用没有使用 Apple 开发者签名，所以每次更新后第一次读取仍会询问一次，请选择“始终允许”。
- **会议**：修复会议纪要的崩溃、负责人误判和内容静默丢失；转写改为真正追加；格式错误的事实计入未通过数。

209 项 Python 检查、13 组 Swift 检查、应用构建与签名结构校验，以及设置界面启动检查通过。当前公开构建未做 Apple 公证。
