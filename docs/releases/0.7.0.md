# freetalk 0.7.0

口述整理在 51 条测试句（你确认过的 22 条加 29 条同类变体）上，本机模型完全正确的条数从 15 条提高到 51 条。以后改整理规则或提示词，都先在本机跑这套测试，没有变差才采用。云端分成快模型和强模型，按功能开关；新增翻译输入、窗口文字识别和富文本列表。

- **整理更准**：数字按语境写，“两个人”“第一组”保留中文，“下午三点十五”写成“下午3点15”，“v 二点三点一”写成“v2.3.1”。逐个念出的字母合成缩写（S F T → SFT），词库里的词按词库的大小写（lora → LoRA），“设成十六”写成“设成16”。输入框、窗口标题或屏幕上已经写对的人名和术语用来纠正近音字（林小峰 → 林晓峰，下普比率 → 夏普比率）。英文改口（no wait、sorry、I mean）生效。以“吗”结尾的句子和请对方确认的问句补问号。“第一，第二，第三”排成 1. 2. 3. 编号列表。聊天应用里保留“呀、啊、哦”等语气。
- **云端模型**：在「语音输入 → 专业配置 → 云端模型」填一个服务，分别指定快模型（口述整理、翻译）和强模型（规则优化、会议写作），再按功能勾选是否使用云端。0.6 的云端整理设置会自动沿用。更新后第一次使用云端时，钥匙串会再询问一次，请选择“始终允许”。
- **规则先过测试集**：「常用词与学习 → 整理规则优化」用新旧规则在本机重跑你的修改记录和内置测试集，没有变差就自动采用，否则列出变化由你决定。整理偏好积累到 8 条时，强模型把它们并入整理规则，同样先过测试集；之前手动改过的规则会备份。在「云端模型」勾选“每晚自动优化”后，每晚 00:30 以后电脑空闲时自动运行一次。「整理提示词」改为“检查并保存”：测试集变差时不保存，你仍可以选择“仍然保存”。
- **翻译输入**：按右 Option + T 开始说话，整理后插入译文。在「快捷键」里可以改键、选择目标语言（默认中文译成英文，其他语言译成中文）或关闭。勾选「云端模型 → 翻译输入」时用快模型，否则用本机模型。数字、网址或代码没有原样保留的译文不会插入，改为插入整理后的原文。
- **更多上下文**：辨词时参考光标前后的文字、选中的文字和网页域名。可以在「排版与上下文」勾选“识别窗口里的文字”：可见文字太少时，用 macOS 的文字识别读取目标窗口，需要“屏幕录制”权限。画面不保存、不上传，识别结果和可见文字一样不发送到云端；密码管理器的窗口不读取。
- **富文本列表**：编号列表和分段在支持富文本的应用里粘贴为真正的列表；终端和代码编辑器仍只收到纯文本。可以在「排版与上下文」里关闭。
- **会议**：勾选「云端模型 → 会议深度整理与写作」后，深度整理使用强模型，写作要求仍在会议「选项」里填写。

241 项 Python 检查、15 组 Swift 检查、应用构建与签名结构校验，以及设置界面启动检查通过。当前公开构建未做 Apple 公证。
