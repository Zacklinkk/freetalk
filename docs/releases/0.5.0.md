# freetalk 0.5.0

会议始终先在本机生成基础资料，再按需追加云端深度整理。普通口述改善填充词、数字型号和上下文处理，设置页统一为简约的 macOS 风格。

- **会议快捷键**：右 Option + M 开始或结束会议录音，显示独立的录音状态提示；右 Option 继续用于普通口述。
- **可选深度整理与写作**：展开会议选项，配置 OneAPI 等 OpenAI 兼容服务、模型和写作要求。结果与本地原稿、纪要、脑图分别保留；云端失败不影响基础资料。未配置时不调用云端。
- **口述整理**：普通填充词使用原文候选选择，减少重复生成长段原文造成的延迟；保护有含义的连接词。超时时只保留已完整生成并通过校验的局部修改。
- **数字与术语**：改善版本号、明确编号和已知型号的写法，保护普通词、人名、引用和代码。应用名称、窗口标题可辅助辨词；周围可见文字另行选择开启，仅在本机使用。
- **跨应用输入**：改进 Chromium / Electron 可访问性请求和粘贴事件路径，增加不录音、不发送消息的输入兼容性测试。目标或草稿变化时仍保留结果供复制。
- **会议分段**：避免说话人短暂变化造成极短的 ASR 片段；保留说话人时间区间，区分依次发言与检出的重叠语音。
- **界面与文档**：统一侧栏、表单、会议页和浮窗样式；新增英文 README、真实音频评测说明与复现脚本，更新 agent skill。

真实回放包括张小珺技术访谈和 AliMeeting 四人会议片段。2 分钟四人录音约 35 秒生成本地原稿、基础纪要与脑图；这只是单机样例，多人抢话和专业词仍会识别错误，不是准确率承诺。详见仓库的真实音频评测记录。

137 项 Python 检查、11 组 Swift 检查、应用构建与签名结构校验，以及 Sparkle 安装/重启、取消、坏签名和离线回归通过。更新可能需要 macOS 重新关联原有权限。当前公开构建未做 Apple 公证。
