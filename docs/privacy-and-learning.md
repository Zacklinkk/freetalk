# 数据、上下文与改字学习

## 哪些数据被读取

录音由用户主动触发。应用可以提前准备设备节点和格式，但没有开始录音时不安装录音 tap，也不启动音频引擎采集。录音期间音频仅在内存中流向本机模型，不保存音频文件。

启用输入框上下文时，开始录音后通过辅助功能 API 冻结当前目标，最多使用开头 500 字和光标附近 1,000 字作为辨词背景。它不遍历其他窗口或读取整段聊天历史，不把剪贴板作为模型上下文。密码框不作为正常输入目标。

插入前重新核对目标、草稿内容和选区。不能确认目标时，结果保留在文字历史供手动复制。模型输出不被当作可执行命令。

## 常用词怎么生效

词库最多 200 个词，每次录音冻结一份。当前输入框实际出现的词优先，最多 48 个词作为 ASR 提示；整理模型也可以用这些已知拼写作局部辨词参考。只合并有依据的大小写或英文缩写，不把所有相近发音都改成词库词。

## 从改字中学习

成功插入后，开启学习时，仅观察同一输入框中本次插入区域附近的修改，最多 90 秒。离开输入框或开始下一次录音就停止。

短词修改稳定约 1.5 秒后，程序检查词边界、近音/拼写、数字和否定变化。符合条件的修正保存为候选关系，并把正确拼写加入词库，显示 5 秒可撤销提示。标点调整、整段改写、数量变化或意图反转不当作词语学习。撤销恢复此次记录与新增词。

**这不是字符串替换表，也没有训练模型权重。** 错词关系供回看、撤销和约束，正确词提供软提示。正常的旧词仍然允许被识别出来；没有本次语音/原稿证据时，整理层不能强行套用历史同音纠正。当前没有实现积累音频标注或 LoRA 微调，因为默认根本不保留音频。

## 本地保存

`~/Library/Application Support/freetalk/` 包含配置、最多 500 条文字历史、词库、学习记录和少量启动诊断。文字历史包含原稿、结果、耗时与插入状态，不保存输入框背景。超出 500 条时淘汰最旧记录。

数据文件使用本地文件权限限制访问，但没有独立加密。设备诊断包含设备名称、连接类型和阶段耗时，不包含音频或文稿。日志用于错误诊断，分享前仍应人工检查。首次引导试说不写入普通历史。

模型安装阶段连接公开的下载站点，仅获取安装工具、依赖和模型；不发送个人转写内容。项目不包含遥测服务或自动上传逻辑。
